# **App Name**: MicroFinance Ally

## Core Features:

- Loan Calculator: Calculate loan payments based on principal, interest rate, and term.
- Provider Comparison: Display and compare different microfinance providers based on key features.
- Personalized Recommendations: AI-powered tool which will analyze user's financial situation to suggest suitable loan products. LLM reasoning tool to provide appropriate financial advise in the recommendation.
- Customer Support Chat: Provide a chat interface for users to get immediate assistance from the customer support team.
- Cookie Consent: Implement a cookie consent banner to comply with privacy regulations.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to evoke trust and financial stability.
- Background color: Very light blue (#F0F8FF), almost white, for a clean and calming effect.
- Accent color: Light sea green (#20B2AA) for calls to action and highlighting important information.
- Body text: 'PT Sans' (sans-serif) to provide a modern look and readability. Headline Font: 'Playfair' (serif), as a pairing.
- Use simple, clean icons from a set like Remix Icon for clarity.
- Use a grid-based layout for a clear, structured display of information.
- Use subtle transitions for button hovers and page changes to give a bit of delight
